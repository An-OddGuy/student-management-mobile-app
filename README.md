# Student Management Mobile App

A mobile application designed to provide a convenient and user-friendly platform for managing student information on mobile devices.

## Features

- 📋 View student records
- ➕ Add new students
- ✏️ Edit student information
- 🗑️ Delete student records
- 🔍 Search and filter students
- 📊 View student details and information
- 🔗 Integration with the Student Management Backend
- 📱 Mobile-friendly and responsive interface
